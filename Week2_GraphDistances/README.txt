Compilation
Keep the TeX file and all three PNG files in the same folder.
Use a standard TeX Live or MiKTeX installation with Beamer and TikZ.
Run twice:
  pdflatex distance_in_graphs.tex
  pdflatex distance_in_graphs.tex

For Overleaf, upload this ZIP, select distance_in_graphs.tex as the main document,
and use pdfLaTeX. Other diagrams are drawn directly in TikZ; no external assets
or bibliography files are required.
